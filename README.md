# Core Intervention Mechanism
the adopted codes (from Dong et al., 2024, Nature Neuroscience) studying the core common mechanism in non-pharmacological intervention

We will update the codes and the dataset (along with the results figures) ASAP, so please frequently refresh your website and check the latest coeds ;)

Before our RCT article is published, this project would be private. When the article is online, we will add the DOI to this readme file for citation.

Data (after processing, anonymized and harmonized) has been placed in the "datasets" and this shared link: https://1drv.ms/f/c/56c6c3b9382ce86a/UgBq6Cw4ucPGIIBWaFMFAAAAAKfC5tckoj_Ijiw

Attention: the above data (.mat) is only suitable for the current intervention study. Please directly process the raw .nii.gz files if you'd like to merge the four datasets with your own datasets (in your way).

GOOD NEWS! Now if you want to process the data in your way, you can now sign in the Science Databank for our open-access datasets! Pls refer to our latest published article:

Jin, X., Tang, W., Zheng, Z. et al. An open multimodal database of non-pharmacological interventions in older adults. Sci Data (2026). https://doi.org/10.1038/s41597-026-08150-x

Jin, X., Tang, W., Yin, S. et al. An open dataset for cognitive training effects on brain and cognition in older adults with subjective memory decline. Science Data Bank. doi:10.57760/sciencedb.psych.00863 (2026).

Thanks for reading our work! We hope this work valuable for all clinicians and researchers in cognitive neuroscience!
